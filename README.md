# Dream Events
Sitio web informativo y de presentación diseñado para una empresa de planificación, decoración y organización de eventos.

🌐 **Sitio web en vivo:** https://crismely-baez.github.io/Dream-Events/

## Secciones del proyecto

* **Inicio (`index.html`):** Presentación principal de la marca, propuesta de valor y acceso rápido a las secciones del sitio.
* **Servicios (`servicios.html`):** Detalle de los paquetes y servicios disponibles para distintos tipos de eventos.
* **Galería (`galeria.html`):** Muestra visual de montajes, decoraciones y eventos realizados.

## Tecnologías utilizadas

* **HTML5:** Estructura semántica de las páginas.
* **CSS3:** Estilos personalizados, diseño responsivo y maquetación individual por sección (`index.css`, `servicios.css`, `galeria.css`).
* **GitHub Pages:** Alojamiento y despliegue continuo del sitio web.
